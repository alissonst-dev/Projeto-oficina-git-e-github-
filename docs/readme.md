# Git e GitHub na Prática

Projeto de extensão desenvolvido para a disciplina de Extensão da UTFPR — Campus Guarapuava, voltado aos alunos do Ensino Médio Técnico do IFPR, com foco em Git, GitHub e desenvolvimento colaborativo.

---

## Sobre o Projeto

O projeto tem como objetivo introduzir os alunos aos conceitos de controle de versão e colaboração em projetos de software utilizando Git e GitHub, aproximando os participantes das práticas utilizadas no mercado de tecnologia.

As oficinas serão desenvolvidas em formato prático, permitindo que os alunos aprendam através da criação e gerenciamento de repositórios reais.

---

## Conteúdos Abordados

- Introdução ao controle de versão
- Git e GitHub
- Criação de repositórios
- Commits e histórico de alterações
- Branches e merge
- Repositórios remotos
- Fork e Pull Request
- Fluxo colaborativo
- Projeto prático em equipe

---

## Público-Alvo

Alunos do Ensino Médio Técnico do IFPR interessados em tecnologia e desenvolvimento de software.
